🐰 DeskBud 豁牙小兔 · Windows

桌面宠物绿色免安装单文件程序

一只会跑会跳、会冒话的兔子，常驻你的桌面。本文教你 3 分钟装上开玩。

一、这是什么

豁牙小兔是养在桌面上的宠物兔子：

  • 只有兔子本体可见，背景完全透明，不挡视线；
  • 平时在桌面溜达，会自己起跳、飘落、做小动作（打哈欠、伸懒腰、眨眼…）；
  • 头顶偶尔冒出一句可爱语录；
  • 不收集、不上传任何个人信息，联网只为获取公开语录，放心用。

二、下载与运行

  1. 从分享渠道下载 DeskBud_Rabbit_Win_v版本号.exe（单个文件，约 60–70MB）。
  2. 若为压缩包，先解压。建议放到纯英文路径（如 D:\Pets\），个别老系统对中文路径不友好。
  3. 双击即运行，免安装、不用装任何东西。

第一次打开请等 1–3 秒兔子才出现，属正常，不是卡死。

三、第一次运行：可能被拦一下（常见，别慌）

这类小软件没做商业签名，Windows 或杀毒软件可能拦一次，都是误报，放行即可，以后就顺了。

1）杀毒软件提示"病毒 / 已隔离 / 已删除"

→ 在 360 / 火绒 / Windows 安全中心里，把 DeskBud_Rabbit_Win_v版本号.exe 加白名单 / 信任 / 允许运行，再重新双击。被删掉的话，重新下载一次再放行。

2）弹窗"Windows 已保护你的电脑"

→ 点「更多信息」→「仍要运行」即可。

四、怎么玩

  • 单击兔子：起跳后像降落伞一样慢慢飘落；
  • 拖拽兔子：随手挪位置，松手后自己飘落；
  • 鼠标悬停：移动或下落会暂停，移开继续；
  • 右键菜单：向左走 / 向右走（跑得飞快）、自定义画圈（拖个矩形它绕着走）、缩放、退出；
  • 关于：右键菜单里可看版本号与日期。

待机小动作是随机的，多等一会儿就能看到它换花样。

五、头顶的气泡

  • 偶尔冒出一句兔子语录，联网自动拉取最新内容，离线也有内置的，不联网也能玩；
  • 文字会自动黑/白适配桌面明暗，保证看得清，属正常设计。

六、常见问题

Q：被杀毒软件删了 / 报毒？
A：误报，见「三」加白名单即可。

Q：双击没反应 / 一闪而过？
A：先看「七」排查；搞不定就把程序旁边的 DeskBud豁牙小兔日志.txt 发给作者（见「七」第 3 条），立刻能定位。

Q：兔子挡着我干活？
A：它是置顶的，拖到屏幕角落，或右键让它停下来。

Q：怎么知道是不是新版？
A：右键菜单「关于」里有版本号；新版本去原下载渠道重新拿。

七、跑不起来的排查（有的电脑能跑、有的不能？）

不是软件挑电脑，是电脑环境差异。按顺序对号入座，3 分钟能定位。

1）先看系统是否达标（最常见、也最无解）

需要 64 位 Windows 10（2018 年 10 月后的版本）或 Windows 11。Win7 / Win8 / 32 位系统跑不了，这类电脑装任何版本都不行。

自查：按 Win+R 输入 winver 回车——显示"版本 1809"及以上或 11 即可；「此电脑」右键→属性看 64 位。

2）再查是否被杀软静默拦掉

装了 360 / 火绒 / 腾讯管家的电脑常"双击没反应"或"提示已删除"——去杀软「信任区」加白名单并重新下载，把程序所在文件夹也加信任。

3）一闪而过 / 秒退？看启动日志（最快）

程序每次启动都会在它自己旁边生成 DeskBud豁牙小兔日志.txt。跑不起来时把这个文件直接发给作者即可定位。

如果连这个文件都没有：说明程序没被允许运行（杀软删了或系统太老），回到上面 1、2 条查。

4）其他少见情况

提示缺 .dll：装一下微软"Visual C++ 运行库"再试；很老的显卡可能画面异常，属正常限制。

🐰 DeskBud Bucky Rabbit · Windows

Desktop petPortableSingle file

A bunny that runs, hops and chats, living right on your desktop. This guide gets you started in 3 minutes.

1. What is it

Bucky Rabbit is a pet bunny that lives on your desktop:

  • Only the bunny itself is visible on a fully transparent background — nothing blocks your view;
  • It wanders around, hops, floats down and does little things (yawns, stretches, blinks…);
  • It occasionally bubbles a cute line above its head;
  • It collects or uploads no personal data. The only network use is fetching public quotes — safe to use.

2. Download & run

  1. Download DeskBud_Rabbit_Win_vVERSION.exe from the release channel (one file, about 60–70 MB).
  2. If it comes in a zip, extract it first. Use an English-only path (e.g. D:\Pets\) — some older systems dislike Chinese paths.
  3. Double-click to run. No installation, nothing else to install.

On first launch the bunny may take 1–3 seconds to appear — that's normal, not a freeze.

3. First run: you may get a warning (common, don't panic)

This small app has no commercial code signing, so Windows or antivirus may flag it once. It's a false positive — just allow it and you're set.

1) Antivirus says "virus / quarantined / deleted"

→ In 360 / Huorong / Windows Security, add DeskBud_Rabbit_Win_vVERSION.exe to the whitelist / trusted / allowed list, then double-click again. If it was deleted, download once more and allow it.

2) "Windows protected your PC" dialog

→ Click More info → Run anyway.

4. How to play

  • Click the bunny: it hops up, then floats down slowly like a parachute;
  • Drag the bunny: move it anywhere; it floats down when released;
  • Hover with the mouse: moving / falling pauses, and resumes when you move away;
  • Right-click menu: walk left / walk right (fast!), draw a custom orbit (drag a rectangle for it to circle), resize, quit;
  • About: version number and date live in the right-click menu.

Idle animations are random — wait a while and you'll see it switch tricks.

5. The bubble above its head

  • It occasionally bubbles a rabbit quote. Fresh lines are fetched online, but built-in ones work offline too — it plays fine without a network;
  • Text auto-switches black/white to stay readable on light or dark wallpapers — that's by design.

6. FAQ

Q: Antivirus deleted / flagged it?
A: False positive — see section 3 and whitelist it.

Q: Double-click does nothing / flashes and closes?
A: See section 7. If that doesn't help, send the author the DeskBud豁牙小兔日志.txt sitting next to the app (section 7, item 3) and it can be pinpointed quickly.

Q: The bunny is in my way while working?
A: It's always-on-top. Drag it to a corner, or right-click to make it stop.

Q: How do I know if I have the latest version?
A: Version number is in the right-click menu → About. New builds are published on the original download channel.

7. Troubleshooting "it won't run" (works on some PCs, not others?)

It's not that the app "picks" computers — it's environment differences. Work through these in order and you'll usually find it in 3 minutes.

1) Check the system first (most common, and most hopeless)

You need 64-bit Windows 10 (version 1809 or later) or Windows 11. Win7 / Win8 / 32-bit systems cannot run it — no build will work on those.

Self-check: press Win+R, type winver, Enter — "Version 1809" or newer, or 11, is fine; right-click "This PC" → Properties to confirm 64-bit.

2) Then check for silently blocked antivirus

PCs with 360 / Huorong / Tencent PC Manager often show "double-click does nothing" or "deleted" — whitelist it in the antivirus "trust zone", re-download, and also trust the folder the app lives in.

3) Flashes / quits instantly? Check the startup log (fastest)

The app writes DeskBud豁牙小兔日志.txt next to itself on every launch. Send that file to the author if it won't start — it pinpoints the cause immediately.

If even that file doesn't exist: the app was never allowed to run (antivirus removed it, or the OS is too old) — go back to items 1 and 2.

4) Other rare cases

Missing .dll: install the Microsoft "Visual C++ Redistributable" and retry. Very old GPUs may show glitches — a normal limitation.
