2Three steps to start

Drag it into Applications and you're done — under a minute.

1

Download & drag into Applications

Get the Mac package (.dmg or .zip), open it, and drag DeskBud into the Applications folder. Any location works, but don't run it straight from the dmg / zip — drag it out first.

2

Blocked on first open? Just allow it

The app isn't code-signed (notarized), so macOS will step in once on first launch — that's normal. If you see "cannot verify the developer", right-click DeskBud in Finder → "Open" → "Open" again; or go to System Settings → Privacy & Security and click "Open Anyway". Allow it once and it'll be smooth afterwards (see FAQ below for details).

3

Open DeskBud

On the very first launch, wait 1–3 seconds before your pet appears. That's normal, not a freeze. Then it starts living its life on your desktop.

5FAQ

Open a question for the answer — most issues take 10 seconds to fix.

"Can't verify the developer / can't be opened"?
Normal — the app isn't notarized. Either way works:
① In Finder, right-click DeskBud → "Open" → "Open" again — right-click, not double-click;
② Or open System Settings → Privacy & Security and click "Open Anyway".
Allow it once and it opens normally afterwards.
"Damaged and can't be opened"?
macOS labels "not notarized" apps as damaged — the app itself is fine. Open Terminal (search "Terminal" in Launchpad), paste this line and press Enter:
xattr -cr /Applications/DeskBud.app
(If DeskBud isn't in your Applications folder, replace the path with where it actually is.)
Double-click does nothing / window flashes?
First make sure you're not running it straight from the dmg / zip (drag it into Applications first). If it still won't start, check the launch log: every launch creates a .txt log file right next to the program. Send that file to the author for a quick diagnosis (contact via deskbud.xyz).
It blocks my work?
It always stays on top. Just drag it into a screen corner, or right-click to pause / hide it.
How do I know if it's the latest version?
Right-click menu → "About" shows the version number and date. For a new version, grab it from where you got this one and install over it.
💡 Tip: Your pet can't be broken, no matter how you play with it. If it does something odd, that's not a bug — that's personality.
