2Three steps to start

No installer, nothing to set up. Under a minute.

1

Download & unzip

Get DeskBud_Win_vVERSION.exe (a single file, about 60–70MB). If it's in a zip, unzip it first. A path with only English characters is recommended (e.g. D:\Pets\) — some older systems don't like non-ASCII paths.

2

Blocked once? Just allow it

The app isn't code-signed, so your antivirus or Windows may false-flag it once — that's normal. If your antivirus complains, add it to the whitelist / trust list; if you see "Windows protected your PC", click "More info" → "Run anyway". Allow it once and it'll be smooth afterwards.

3

Double-click to run

Double-click the exe — on the very first launch, wait 1–3 seconds before your pet appears. That's normal, not a freeze. Then it starts living its life on your desktop.

5FAQ

Open a question for the answer — most issues take 10 seconds to fix.

Deleted / flagged by my antivirus?
It's a false positive (the app isn't code-signed). In 360 / Huorong / Windows Security, whitelist / trust / allow DeskBud_Win_vVERSION.exe. If it got deleted, download it again and allow it — it won't be flagged again afterwards.
Double-click does nothing / window flashes?
It's not the app being picky — it's environment differences. Check in order:

① System requirements (most common)

Requires 64-bit Windows 10 (October 2018 build or later) or Windows 11. Windows 7/8 and 32-bit systems won't run it. Check: press Win+R, type winver, Enter — "Version 1809" or later, or 11, is fine.

② Silently blocked by antivirus

PCs with 360 / Huorong / Tencent PC Manager often show "double-click does nothing" — whitelist it in the antivirus "trust zone", re-download, and trust the program's folder too.

③ Check the launch log (fastest)

Every launch creates DeskBud豁牙小兔日志.txt (a .txt log) right next to the program. If it won't start, send that file to the author for a quick diagnosis (contact via deskbud.xyz). If no such file exists at all, the program was never allowed to run — go back to ①②.
It blocks my work?
It always stays on top. Just drag it into a screen corner, or right-click to pause / hide it.
How do I know if it's the latest version?
Right-click menu → "About" shows the version number and date. For a new version, grab it from where you got this one and run it in place.
Missing .dll / graphics glitches?
For a missing .dll: install Microsoft's "Visual C++ Redistributable" and try again. Very old GPUs may show glitches — that's a known limitation.
