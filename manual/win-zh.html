2三步玩上

免安装、不用装任何东西，全程不到一分钟。

1

下载并解压

拿到 DeskBud_Win_v版本号.exe（单个文件，约 60–70MB）。若为压缩包先解压，建议放到纯英文路径（如 D:\Pets\），个别老系统对中文路径不友好。

2

被拦一下？放行即可

没做商业签名，杀毒软件或 Windows 可能误报拦一次，都是正常现象：杀软提示就加白名单 / 信任；弹"Windows 已保护你的电脑"就点「更多信息」→「仍要运行」。放行一次，以后就顺了。

3

双击运行

双击 exe——第一次打开请等 1–3 秒兔子才出现，属正常，不是卡死。它落桌后就开始自己过日子了。

6常见问题

点开问题看答案，多数小状况 10 秒解决。

被杀毒软件删了 / 报毒？
误报（程序没做商业签名）。在 360 / 火绒 / Windows 安全中心里把 DeskBud_Win_v版本号.exe 加白名单 / 信任 / 允许运行，被删掉就重新下载一次再放行，以后不会再拦。
双击没反应 / 一闪而过？
不是软件挑电脑，是电脑环境差异，按顺序查：

① 系统是否达标（最常见）

需要 64 位 Windows 10（2018 年 10 月后的版本）或 Windows 11；Win7 / Win8 / 32 位跑不了。自查：按 Win+R 输入 winver 回车，显示"版本 1809"及以上或 11 即可。

② 是否被杀软静默拦掉

装 360 / 火绒 / 腾讯管家的电脑常"双击没反应"——去杀软「信任区」加白名单并重新下载，程序所在文件夹也加信任。

③ 看启动日志（最快）

程序每次启动都会在它自己旁边生成 DeskBud豁牙小兔日志.txt，跑不起来时把这个文件发给作者即可定位（联系方式见 deskbud.xyz）。如果连这个文件都没有，说明程序没被允许运行，回到上面①②查。
兔子挡着我干活？
它是置顶显示的，直接按住拖到屏幕角落，或右键让它停下 / 收起。
怎么知道是不是新版？
右键菜单「关于」里有版本号和日期；新版本去原下载渠道重新拿，直接覆盖运行即可。
提示缺 .dll / 画面异常？
提示缺 .dll：装一下微软"Visual C++ 运行库"再试。很老的显卡可能画面异常，属正常限制。
